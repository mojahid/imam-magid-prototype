# Imam Mohamed Magid — Website Concept Proposal

**Status:** Unofficial proposal prototype; pending approval by Imam Mohamed Magid or his designated representative. Not an authorized website.

This static prototype explores a modern bilingual (English / Arabic) personal website and living archive for Imam Mohamed Magid, combining biography, scholarship, leadership, media, events and source links.

## Run locally

Open `index.html` in a browser. No build dependencies required.

## Deploy

Netlify: use the existing `imam-magid-prototype` project, connect the GitHub repository `mojahid/imam-magid-prototype` as a deploy source, use publish directory `.` and no build command. The `netlify.toml` provides configuration and indexing restrictions.

## Editorial safeguards

- Clearly label the prototype as unapproved until official authorization.
- Obtain rights and consent before using original portraits, personal photography, full articles or recordings.
- Verify biographies, historical dates, titles and translations before public launch.
- Existing external links lead to original publishers; no media is mirrored.
- Replace placeholder contact details only with approved official channels.
